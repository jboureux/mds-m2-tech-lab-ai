# Stratégie Agentic Coding - My Digital Scoop

Bienvenue dans la documentation officielle de la stratégie de développement de **My Digital Scoop (MDS)**. 

Cette application n'est pas seulement un réseau social scolaire ; c'est le résultat d'une méthodologie de co-création innovante entre l'humain et l'IA : l'**Agentic Coding**.

## 🚀 Qu'est-ce que l'Agentic Coding ?

L'Agentic Coding est une approche où le développeur collabore avec un agent IA autonome (ici **Gemini CLI**) pour transformer des concepts en code de production. Contrairement au simple "copier-coller" de snippets, l'agent opère avec une compréhension profonde de l'architecture, du contexte et des contraintes du projet.

## 🏗️ Piliers de la Stratégie

1.  **Contextual Integrity** : Utilisation de fichiers `GEMINI.md` pour fixer les règles d'or.
2.  **PRP Flow (Product Requirements Page)** : Chaque fonctionnalité majeure commence par un document de spécifications structuré.
3.  **Cycle Itératif Plan-Act-Validate** : Aucune modification n'est considérée comme terminée sans une phase de validation empirique (tests unitaires, builds, vérification visuelle).
4.  **Skills Autonomes** : Utilisation de "Skills" spécialisés (Docker, Next.js best practices, UI/UX) pour garantir l'excellence technique.
